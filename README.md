# schoomy-project

## これは何？
スクーミーで作った、眠い学生を起こすためのデバイスです。
明るさと距離を測って、シリアルモニターに状態を表示します。

## 動作内容
- 明るさセンサーで部屋の明るさを測っています。
- 距離センサーで人や物との距離を測っています。
- 現在のプログラムでは、LEDが常に光るようになっています。
- シリアルモニターに「明るさ」「距離」「警告」を表示します。

## 使い方
スクーミーのプロジェクトを開いて実行します。
実行すると、明るさと距離の値がシリアルモニターに表示されます。
